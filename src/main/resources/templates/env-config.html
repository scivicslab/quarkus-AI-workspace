Environment Config

Deployment-wide runtime settings shared by every tool launched from this working directory — real node IPs, per-instance capacity overrides, and similar facts about this environment that are not any single tool's own concern (see CapabilityConfig_260810_oo01 for the motivating example). Kept out of source repositories on purpose. Editing here overwrites the whole file; each tool reads this only when it starts, so a running tool will not pick up a change until it is restarted.
